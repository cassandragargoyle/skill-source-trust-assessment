# Issues

The list of issues, their status and assignee live on GitHub:
<https://github.com/cassandragargoyle/skill-source-trust-assessment/issues>

This directory holds only the long-form write-up of each issue, `NNN-name.md`, where
`NNN` is the GitHub issue number. Finished issues move to [done/](done/).

The workflow is described in
[docs/contributing/ISSUE-MANAGEMENT.md](../contributing/ISSUE-MANAGEMENT.md).
